# 모모네 집 가계부

토끼와 캥거루의 정제된 뱅크샐러드 엑셀을 합치는 월별 가계부입니다. 정제 단계는 별도 프로그램에서 완료합니다.

- `9토끼 (2).xlsx`, `9캥거루.xlsx`처럼 파일명에서 월과 입력자를 자동으로 찾습니다. 연도는 선택한 연도를 사용하며 가져오기 전에 확인할 수 있습니다.
- 같은 연월과 입력자의 파일을 다시 가져오면 해당 범위만 교체합니다. 파일 내부의 동일한 거래 행은 임의 삭제하지 않습니다.
- 가정 전체 수입과 지출을 표시하고 수입은 종류별로 묶습니다. 사람별 합계는 표시하지 않습니다.
- 거래의 토끼·캥거루 표시를 눌러 수정합니다. 메모는 내용 아래에 표시됩니다.
- 카테고리 막대를 누르면 소분류와 상세 거래를 확인할 수 있습니다.
- 브라우저 로컬 저장, 전체 JSON 백업·복원, 월별 XLSX 다운로드를 지원합니다.

## 저장 범위

자동 저장은 현재 브라우저에 한정됩니다. 두 사람의 기기 사이에서 자동 동기화되지 않습니다. 백업 JSON을 Google Drive에 보관한 뒤 다른 기기에서 복원할 수 있습니다. 서로 수정한 백업을 복원할 때는 전체 교체이므로 최신 파일 하나를 기준으로 사용하세요. 자동 공동 저장에는 별도의 인증된 서버 또는 Google Apps Script 연결이 필요합니다.

## GitHub Pages 게시

새 저장소 `momo-household-ledger`를 만들고 이 폴더의 파일을 루트에 올립니다. Settings → Pages → Deploy from a branch → main / root를 선택합니다. 기존 `holaharu` 저장소는 사용하지 않습니다.

실제 가계부 엑셀·백업 JSON은 저장소에 올리지 마세요. 프로그램은 시작할 때 빈 상태이며 가져온 내역은 브라우저에서 처리합니다.

## 라이브러리

SheetJS Community Edition 0.20.3 (Apache-2.0): https://sheetjs.com/ . XLSX 가져오기와 내보내기에 사용합니다. 라이브러리를 포함하므로 외부 CDN 연결 없이 실행됩니다.
