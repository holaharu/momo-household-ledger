# 모모네 집 가계부

정제한 토끼·캥거루 엑셀을 합쳐 월별 가계부와 연간·반기 분석을 보여 줍니다.

- 파일명 `9토끼.xlsx`에서 월·입력자를 제안하고 연도를 확인합니다.
- 수입·지출은 가정 전체로 합산하고 입력자는 색깔로 표시합니다. 표시를 누르면 수정합니다.
- 같은 달·입력자의 파일을 다시 가져오면 그 부분만 교체합니다. 상대방 내역은 유지합니다.
- 두 사람의 업로드가 완료되면 자동 확정합니다. 확정 해제 후 수정하고 다시 확정할 수 있습니다.
- 월간은 수입·지출 목록, 연간·반기는 월별 겹친 선그래프와 지출 원그래프를 표시합니다.
- 그래프에서 월별 합계와 차액을 확인하고, 분류를 눌러 소분류·내역을 조회합니다.
- 선택한 기간의 엑셀 다운로드와 전체 JSON 백업을 지원합니다.

## 저장 방식

GitHub Pages 주소는 브라우저별 저장 버전입니다. 서로 다른 기기의 내역을 공유하지 않습니다.
공동 저장 버전은 Google Apps Script 웹 앱으로 실행합니다. 원본 금융 파일이나 실제 내역을 GitHub에 커밋하지 않습니다.

## Google 공동 저장 설치

1. 새 Apps Script 프로젝트에 `Code.gs`와 `Index.html`을 넣습니다.
2. `setupLedger`를 실행하고 요청 권한을 확인합니다. 거래내역·월별상태 시트가 생성됩니다.
3. `addKangarooAccount`의 이메일 자리표시자를 캥거루 계정으로 변경한 뒤 실행합니다.
4. 생성된 Google Sheets를 캥거루 계정에 편집자로 공유합니다.
5. 웹 앱 배포에서 실행 주체를 **웹 앱에 액세스하는 사용자**, 접근을 Google 계정 사용자로 설정합니다.
6. 배포된 웹 앱 주소를 두 사람이 사용합니다. 계정 허용 목록에 있는 사람만 접근합니다.

토끼 관리자 계정은 두 사람 파일을 업로드·수정할 수 있습니다. 캥거루 계정은 본인 내역만 업로드·수정할 수 있습니다. 두 계정 모두 전체 가계부를 볼 수 있습니다.
동시 업로드는 서버 잠금으로 합쳐 저장하고, 오래된 화면에서 수정하면 최신 내용으로 갱신 후 다시 시도하도록 안내합니다. 최신 내용을 가져오려면 저장 버튼이나 새로고침을 사용합니다.

`Index.html`은 브라우저 화면·CSS·JS를 합친 Apps Script용 파일입니다. SheetJS는 이 저장소의 Pages에서 읽습니다.
